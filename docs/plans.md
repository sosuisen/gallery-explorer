# plans

## ユーザータスク: 複数の項目を選んでドラッグする

### 選択（domain::Selection）
- [ ] 1つだけ選ぶと、前の選択は消える。
- [ ] 加えると、前の選択に足される。
- [ ] 外すと、その項目だけが選択から消える。

### 矩形（domain::band）
- [ ] 2点から作る矩形は、どちらの向きにドラッグしても同じである。
- [ ] 一覧では、矩形と高さが重なる行が選ばれる。
- [ ] グリッドでは、矩形と重なるタイルが選ばれる。
- [ ] 項目の外の矩形では、何も選ばれない。

### 押下（Explorer）
- [ ] 押した項目だけが選ばれる。
- [ ] Ctrlで押すと、項目が選択に加わる。
- [ ] 選択された項目をCtrlで押して離すと、選択から外れる。
- [ ] 複数を選んだまま選択された項目を押しても、選択は変わらない。離すと、その項目だけが選ばれる。
- [ ] 矢印キーを押すと、移った項目だけが選ばれる。

### 矩形での選択（Explorer）
- [ ] 空いた場所から矩形を広げると、重なる項目が選ばれる。
- [ ] Ctrlを押して矩形を広げると、前の選択に加わる。
- [ ] Ctrlなしで空いた場所を押すと、選択が消える。
- [ ] 矩形を終えると、矩形は消える。

### ドラッグ（Explorer）
- [ ] 選択された項目のドラッグでは、選択されたすべての項目が渡る。
- [ ] 選択されていない項目のドラッグでは、その項目だけが渡る。

### 読み直し（Explorer）
- [ ] 読み直しても、選択された項目はすべて選択されたままである。
