## ユーザータスク: Shift+クリックとShift+矢印キーで範囲を選ぶ

### 範囲（domain::Selection）
- [ ] 範囲を選ぶと、起点から指定の行までが選ばれ、前の選択は消える。起点は変わらない。
- [ ] 起点がないときに範囲を選ぶと、指定の行だけが選ばれ、そこが起点になる。
- [ ] 範囲を加えると、前の選択に足される。

### Shift+クリック（Explorer）
- [ ] Shift+クリックで、最後にShiftなしで押した項目から、押した項目までが選ばれる。
- [ ] Shift+クリックを続けると、同じ起点から範囲が選び直される。
- [ ] Ctrl+Shift+クリックで、起点からの範囲が今の選択に加わる。

### Shift+矢印キー（Explorer）
- [ ] Shift+矢印キーで、起点から移った項目までが選ばれる。
- [ ] グリッドでは、Shift+上下キーで、起点から真上・真下の項目までが選ばれる。

### 読み直し（Explorer）
- [ ] 読み直しても、起点は同じ項目のままである。
