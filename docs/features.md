# features

テストを要約した機能の一覧である。

- フォルダの中身を見る
  - 起動すると、開始フォルダの中身が一覧に並ぶ。
  - フォルダはファイルより前に並ぶ。名前の順序は、大文字と小文字を区別しない。
  - 開けないフォルダへ移ろうとすると、今のフォルダのままエラーが示される。
  - 移動に成功すると、前のエラーは消える。
- 表示順を選ぶ
  - 表示順は、名前の昇順・降順、更新日の昇順・降順から選べる。起動したときは、名前の昇順である。
  - どの表示順でも、フォルダはファイルより前に並ぶ。
  - 更新日が同じなら、名前の昇順に並ぶ。
  - お気に入りから開くと、ほかの表示順を選んでいても、更新日の降順で並ぶ。
  - フォルダを読むと、項目の更新日がわかる。
  - 表示順を変えると、今のフォルダの項目が並び直る。選択していた項目は選択されたままである。
  - フォルダを移っても、読み直しても、表示順は変わらない。
- 変化をすぐに反映する
  - フォルダにファイルが追加されると、変化が通知される。
  - フォルダからファイルが削除されると、変化が通知される。
  - 読み直すと、追加されたファイルが一覧に並び、そのサムネイルも出る。
  - 読み直すと、削除されたファイルは一覧から消える。
  - 前に項目が増えても、選択していた項目は選択されたままである。
  - 選択していた項目が消えると、選択はなくなる。
  - 読み直しの前後の押下は、ダブルクリックにならない。
  - 今のフォルダが消えると、一覧は空になり、エラーが示される。
  - 変化がないまま取り消されると、待つのをやめる。
  - 監視をやめると、待つのをやめる。
  - 存在しないフォルダは監視できない。
- グリッドで見る
  - 起動したときは、一覧で表示される。
  - お気に入りから開くと、一覧で見ていてもグリッドで表示される。
  - 表示を切り替えると、一覧とグリッドが交互になる。
  - フォルダを移っても、表示の方法は変わらない。
  - グリッドでは、画像ファイルはサムネイルで、それ以外はアイコンで示される。
  - 一覧でも、グリッドと同じサムネイルが、6割の大きさで示される。
  - 画像の拡張子のファイルは、大文字と小文字を問わず画像である。
  - 画像でない拡張子のファイルと、拡張子のないファイルは、画像でない。
  - 画像の拡張子の名前を持つフォルダは、画像でない。
  - 画像を読むURIでは、日本語の文字はそのまま残る。そのため、日本語の名前のフォルダでも画像が出る。
  - 画像を読むURIでは、空白と`#`と`%`はエンコードされる。
- グリッドで画像以外のファイルのサムネイルを見る
  - 画像でないファイルの一覧には、フォルダも画像ファイルも含まれない。
  - サムネイルを作れたファイルだけが、そのサムネイルと組になる。作れないファイルは、アイコンのままである。
  - 取り消されると、残りのファイルのサムネイルは作らない。
  - 作られたサムネイルが、そのファイルのサムネイルになる。
  - 前のフォルダのために作ったサムネイルは、無視される。
  - フォルダを移ると、前のフォルダのサムネイルは消える。
  - サムネイルは、BMPのバイト列としてWinUIに渡される。
  - BMPのヘッダーには、ファイルの大きさ、画素の位置、幅と高さが書かれる。
  - 画素は、下の行から順に書かれる。
  - すべての画素のアルファが0なら、不透明として書かれる。
  - 画素の数が幅と高さに合わないと、止まる。
- グリッドでフォルダの1枚目の画像を見る
  - フォルダの1枚目の画像は、名前順で最初の画像ファイルである。
  - 子フォルダの中の画像は、1枚目の画像にならない。
  - 読めないフォルダには、1枚目の画像がない。
  - 画像のあるフォルダだけが、その1枚目の画像と組になる。
  - 取り消されると、残りのフォルダは調べない。
  - フォルダの一覧には、ファイルが含まれない。
  - 見つかった1枚目の画像が、そのフォルダの表紙になる。表紙には、フォルダの小さなアイコンが重なる。
  - 前のフォルダのために探した表紙は、無視される。
  - フォルダを移ると、前のフォルダの表紙は消える。
  - 読み直しても、新しい表紙が届くまでは、前の表紙が残る。
- 一覧から開く
  - 押した行が、選択された行になる。
  - フォルダを移っても、アニメーションはない。新しい項目がすぐに出る。
  - フォルダをダブルクリックすると、そのフォルダの中身が一覧に並ぶ。
  - ファイルをダブルクリックすると、既定のアプリで開く。フォルダは変わらない。
  - ダブルクリックは、同じ行への500ms以内の2回の押下である。
  - フォルダを移った直後の押下は、1回目として数える。
- キーで選んで開く
  - 何も選ばれていないときに矢印キーを押すと、最初の項目が選ばれる。項目がなければ、何も選ばれない。
  - 一覧では、上下キーで1つ上と1つ下の行が選ばれる。最初と最後の行では、選択は動かない。
  - 一覧では、左右キーを押しても、選択は動かない。
  - グリッドでは、上下キーで真上と真下のタイルが選ばれる。
  - グリッドで下の行が短く、真下にタイルがないときは、下キーで最後のタイルが選ばれる。
  - グリッドでは、左右キーで1つ前と1つ後のタイルが選ばれる。行の端では、隣の行へ移る。最初と最後のタイルでは、選択は動かない。
  - Enterを押すと、選ばれたフォルダの中身が並ぶ。選ばれたファイルは、既定のアプリで開く。フォルダは変わらない。
- パンくずで移る
  - パスは、ドライブから今のフォルダまでのパンくずに分かれる。
  - パンくずを押すと、そのフォルダへ移る。
  - 同じ名前が今のフォルダと親にあるときは、親へ移る。
  - 「上へ」で親フォルダへ移る。Backspaceキーでも、同じく親フォルダへ移る。
- ツリーで移る
  - ツリーのルートは、存在するドライブである。
  - フォルダを展開すると、子フォルダだけが1段深く並ぶ。もう一度押すと折りたたまれる。
  - ツリーのフォルダを開くと、一覧がそのフォルダになり、ツリーでも展開される。
- お気に入り
  - 今のフォルダをお気に入りに追加できる。もう一度押すと外れる。
  - お気に入りは、一覧から個別に削除できる。
  - お気に入りの行を選ぶと、その行のフォルダへ移る。
  - お気に入りは、上下のドラッグで並べ替えられる。並べ替えた順序は、次の起動でも残っている。
  - お気に入りは、次の起動でも残っている。
  - お気に入りのファイルが壊れていると、お気に入りは空で、エラーが示される。
- エクスプローラーで開く
  - 一覧とグリッドの項目、お気に入り、ツリーのフォルダを右クリックすると、「エクスプローラーで開く」のメニューが出る。
  - 一覧とグリッドの項目のない場所を右クリックすると、今のフォルダの「エクスプローラーで開く」だけのメニューが出る。
  - フォルダは、そのフォルダをエクスプローラーで開く。
  - ファイルは、そのファイルを選んだ状態で、親フォルダをエクスプローラーで開く。
  - メニューは、マウスでだけ選べる。キーボードでは選べない。
- 削除する
  - 一覧とグリッドの項目を右クリックすると、「削除」のメニューも出る。選ぶと、項目がごみ箱へ移り、一覧から消える。
  - 確認は出ない。ごみ箱に入らない項目だけは、完全に削除してよいかをWindowsが尋ねる。
  - お気に入りとツリーのフォルダは、メニューから削除できない。
- ほかのアプリへドラッグする
  - 一覧とグリッドの項目を、エクスプローラーやほかのアプリのウィンドウへドラッグできる。ファイルもフォルダもドラッグできる。
  - 選んでいない項目も、そのままドラッグできる。
  - コピー・移動・ショートカットの作成は、エクスプローラーと同じキーで選ぶ。
